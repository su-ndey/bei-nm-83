# Lab 4 - LU Factorization and Iterative Methods

This lab was given to me in two documents, so I have organised my work in two parts.

| Folder | Topic |
|---|---|
| `part1_lu_factorization/` | Doolittle Method, Crout's Method |
| `part2_iterative_methods/` | Gauss-Jacobi Method, Gauss-Seidel Method |

Each part folder contains its own `README.md` (objective, theory, results and
discussion), `ALGORITHM.md` (algorithms and pseudocode), `OUTPUT.md` (the full
console output) and the Python programs.

## Requirements

None - all four programs are written in pure Python using nested lists.
